Data Analytics Project
Overview

This project demonstrates an end-to-end data analytics workflow, from data collection and cleaning to visualization and reporting. The goal is to transform raw data into meaningful insights using Python, SQL, and Power BI.

Dataset
Dataset: Customer Shopping Behavior Dataset
Format: CSV
Description: Contains customer demographics, purchasing behavior, payment methods, product categories, and transaction details used for business analysis.
Tools & Technologies
Python (Pandas, NumPy, Matplotlib, Seaborn)
Jupyter Notebook
PostgreSQL / MySQL
SQL
Power BI
Gamma (Presentation)
Git & GitHub
Project Workflow
1. Data Loading
Imported the dataset into Python.
Explored data structure and checked data types.
2. Exploratory Data Analysis (EDA)
Generated summary statistics.
Identified missing values and duplicates.
Analyzed customer demographics and purchase patterns.
Created visualizations to understand trends.
3. Data Cleaning
Removed duplicates.
Handled missing values.
Corrected inconsistent data formats.
Prepared data for analysis.
4. SQL Analysis
Imported cleaned data into PostgreSQL/MySQL.
Wrote SQL queries to analyze:
Customer spending
Product performance
Payment methods
Sales trends
Customer segmentation
5. Power BI Dashboard

Created an interactive dashboard featuring:

Sales Overview
Customer Insights
Product Performance
Payment Analysis
Filters and Slicers for dynamic reporting
6. Report & Presentation
Summarized key business insights.
Created a professional presentation using Gamma.
Dashboard Highlights
Total Sales
Average Purchase Value
Top Product Categories
Customer Demographics
Payment Method Distribution
Monthly Sales Trends
Key Results
Identified top-performing product categories.
Analyzed customer purchasing behavior.
Discovered spending trends across customer segments.
Built an interactive dashboard for decision-making.
